# Scheda PureNote 3.0.2

Testi e asset per `bbnss.test.purenote`, italiano e inglese. Le schermate mostrano
l’interfaccia italiana effettiva, anche nella scheda inglese che lo dichiara.
`listing.json` contiene titolo, descrizioni e ordine esatto delle immagini.

Le schermate provengono dal test UI del commit `37befc2`, run GitHub
`40593773155` del 27 ottobre 2026. Sono acquisizioni Kivy desktop della stessa
interfaccia del progetto, presentate con una cornice e testi promozionali;
non sono catture da un dispositivo Android. Le note sono dati dimostrativi
definiti nel test `tests/ui_smoke.py`, senza contenuti personali.

Screenshot: 1080 × 1920, PNG RGB. Feature graphic: 1024 × 500, PNG RGB.
Icona: 512 × 512, derivata dall’icona approvata del progetto.
La sequenza presenta scrittura offline e ricerca nelle note. L’ipotesi è che
mostrare subito questi due usi renda la scheda più chiara; non sono disponibili
dati sufficienti per affermare un miglioramento della conversione.

I testi si basano su README e codice: nessuna promessa di cifratura, sincronizzazione
cloud o tokenizzazione esatta. Il backup manuale è distinto dal backup Android,
disabilitato nell’app. Pubblicare gli asset insieme alla nuova versione, dopo
firma e controlli, per mantenere coerenti scheda e applicazione distribuita.
